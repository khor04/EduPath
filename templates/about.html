About EduPath

Smart Academic Performance Analysis & Career Recommendation System

Introduction

EduPath is a web-based academic performance analysis system developed to help students monitor, analyse, and predict their academic performance through intelligent transcript processing and data visualization features.

System Objectives

Performance Analysis

Analyse GPA and CGPA performance trends across semesters.

Academic Insights

Provide meaningful insights to support academic planning.

Career Recommendation

Recommend suitable career pathways based on academic results.

Main Features

Transcript Upload
Performance Analysis
CGPA Prediction
Peer Benchmarking
Career Recommendation
User Profile Management

Our Mission

EduPath aims to provide students with a smarter and more interactive platform for understanding academic progress and planning future career pathways.
